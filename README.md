# CORLIVA — Director of Nursing Portal

Clickable prototype of the Director of Nursing web portal for the CORLIVA home care platform. Built from the Care Supervisor portal (the Director can do everything a Care Supervisor does, for the whole agency) plus the duties in the agency's Director of Nursing job description. Same design system as the other CORLIVA portals.

**Pages:** Sign in · My work · Care Supervisors · Clients’ health · Quality and risk · Incidents · Visit approvals · Care plans · Checks · Clients · Schedule · Today’s visits · Caregivers · Reviews and training (+ training session screen) · Settings

```
npm install
npm run dev
```

Demo sign-in: any email and password, then security code 246810. See `AGENTS.md` for the design rules and every flow.
